# commandexecutorinstall specifications

This are the specifications for the [`commandexecutorinstall` package](README.md).

This document extends the parent specifications [installutils.spec.md](../installutils.spec.md).

## Implementation

- Use `commandexecutorfile` and `commandexecutorfileoo` package instead of `nativefiles` or `nativefilesoo`.
- Use `commandexecutortempfile` and `commandexecutortempfileoo` package instead of `tempfiles` or `tempfilesoo`.
