# filesoptions

Options structs used by the [`filesutils`](../README.md) package functions.

## Specifications

For specifications see [filesutils.spec.md](../filesutils.spec.md) and [constitution.md](/constitution.md).

## Usage

This package provides option structs for configuring file operations:

- [`CopyOptions`](CopyOptions.go): Options for copying files
- [`CreateOptions`](CreateOptions.go): Options for creating files
- [`DeleteOptions`](DeleteOptions.go): Options for deleting files
- [`MoveOptions`](MoveOptions.go): Options for moving files
- [`ReadOptions`](ReadOptions.go): Options for reading files
