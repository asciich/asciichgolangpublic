# commandexecutortempfilesoo package

Object-oriented wrapper around [`commandexecutortempfile`](../commandexecutortempfile/README.md) package.

This package is part of the [`filesutils`](../README.md) package hierarchy.

## Implementation Details

This package provides an object-oriented API for temporary file operations using command executor. It wraps the procedural functions from [`commandexecutortempfile`](../commandexecutortempfile/README.md) in structs with methods.

For the native object-oriented implementation, see [`tempfilesoo`](../tempfilesoo/README.md).

## Specifications

For specifications see [filesutils.spec.md](../filesutils.spec.md) and [constitution.md](/constitution.md).
