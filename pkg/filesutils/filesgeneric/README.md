# filesgeneric

Generic implementations for the [`filesutils`](../README.md) package.

## Specifications

For specifications see [filesutils.spec.md](../filesutils.spec.md) and [constitution.md](/constitution.md).

## Usage

This package provides generic base implementations for file operations:

- [`FileBase`](filebase.go): Base implementation for file operations
- [`DirectoryBase`](directorybase.go): Base implementation for directory operations
