# cloudutils

Work with (public) clouds like Exoscale, AWS, GCP...

## Subpackages

* [exoscaleutils](./exoscaleutils/): Work with Exoscale cloud.
    * [exoscalenativeclient](./exoscaleutils/exoscalenativeclient/): Non object-oriented Exoscale client.
    * [exoscalenativeclientoo](./exoscaleutils/exoscalenativeclientoo/): Object-oriented Exoscale client.
