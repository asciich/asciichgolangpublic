# userscmd specifications

This are the specifications for the [`userscmd` package](README.md).

This document extends the parent specifications [defaultclicommands.spec.md](../../../../defaultclicommands.spec.md).

## Implementation

- The `users` command must implement the subcommands:
    - `create` to create a user.
    - `delete` to delete a user.
    - `list` to list all users.
