# floatsutils

Package `floatsutils` provides utility functions for working with float64 values.

## Functions

- `MustRound` - Rounds a float64 to n digits, panics on error
- `MustToString` - Formats a float64 as string, panics on error
- `Round` - Rounds a float64 to n digits
- `ToString` - Formats a float64 as string with max digits after decimal point
