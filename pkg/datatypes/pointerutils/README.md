# pointerutils

Package `pointerutils` provides utility functions for working with pointers.

## Functions

- `CheckIsPointer` - Checks if a value is a pointer, returns error if not
- `GetMemoryAddressAsHexString` - Gets the memory address of a pointer as hex string
- `GetMemoryAddressAsUInt64` - Gets the memory address of a pointer as uint64
- `GetMemoryAddressAsUIntPtr` - Gets the memory address of a pointer as uintptr
- `IsPointer` - Checks if a value is a pointer
- `PointersEqual` - Compares two pointers by their memory addresses
- `ToInt64Pointer` - Creates a pointer to an int64 value
