# gitinterfaces

Interfaces used by the [`gitutils`](../README.md) package.

## Specifications

For specifications see [gitutils.spec.md](../gitutils.spec.md) and [constitution.md](/constitution.md).

## Usage

This package provides interfaces for Git operations:

- [`GitRepository`](GitRepository.go): Interface for Git repository operations
- [`GitCommit`](GitCommit.go): Interface for Git commit operations
- [`GitTag`](GitTag.go): Interface for Git tag operations
- [`GitRemoteConfig`](GitRemoteConfig.go): Interface for Git remote configuration
