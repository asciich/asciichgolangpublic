# commandexecutorgitoo package

Object-oriented wrapper around [`commandexecutorgit`](../commandexecutorgit/README.md) package.

This package is part of the [`gitutils`](../README.md) package hierarchy.

## Implementation Details

This package provides an object-oriented API for Git operations using command executor. It wraps the procedural functions from [`commandexecutorgit`](../commandexecutorgit/README.md) in structs with methods.

For the native object-oriented implementation, see [`nativegitoo`](../nativegitoo/README.md).

## Specifications

For specifications see [gitutils.spec.md](../gitutils.spec.md) and [constitution.md](/constitution.md).
