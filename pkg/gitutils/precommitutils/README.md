# precommitutils package

Utilities for working with [pre-commit](https://pre-commit.com/) config files.

This package is part of the [`gitutils`](../README.md) package hierarchy.

## Contents

- `PreCommitConfigFileConfig`: Represents the content of a `.pre-commit-config.yaml` file (repos, revisions and hooks).
- `PreCommitRunOptions`: Options for running pre-commit.
