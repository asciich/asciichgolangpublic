# gitgeneric

Generic implementations for the [`gitutils`](../README.md) package.

## Specifications

For specifications see [gitutils.spec.md](../gitutils.spec.md) and [constitution.md](/constitution.md).

## Usage

This package provides generic base implementations for Git operations:

- [`GitRepositoryBase`](GitRepositoryBase.go): Base implementation for Git repository operations
- [`GitTagBase`](GitTagBase.go): Base implementation for Git tag operations
