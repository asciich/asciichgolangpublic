# gitlabutils

Utilities for working with GitLab, part of the [`gitutils`](../README.md) package.

## Specifications

For specifications see [gitutils.spec.md](../gitutils.spec.md) and [constitution.md](/constitution.md).

## Usage

This package provides utilities for GitLab-specific operations:

- [`ReadmeDownloader`](readmedownloader.go): Download README files from GitLab repositories
- [`gitlabutils`](gitlabutils.go): General GitLab utility functions
