# nativesshclient package

Implements SSH client operations using native Go libraries. Works only on the local machine.

This package is part of the [`sshutils`](../README.md) package hierarchy.

## Implementation Details

This is the **native** implementation that uses Go's native SSH libraries. For remote execution via command executors, see [`commandexecutorsshclient`](../commandexecutorsshclient/README.md).

## Functions

All functions in this package are also available as convenience functions in the parent [`sshutils`](../README.md) package.

## Specifications

For specifications see [sshutils.spec.md](../sshutils.spec.md) and [constitution.md](/constitution.md).
