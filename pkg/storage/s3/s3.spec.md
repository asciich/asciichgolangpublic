# s3 specifications

This are the specifications for the [`s3` package](README.md).

This document extends the [constitution.md](/constitution.md).

## Implementation

- Calling the `CreateUser` on an already existing user must be idempotent.
    - If a other password is specified the call to `CreateUser` must update it unless `CreateUserOptions.KeepCurrentPasswordIfUserExist` is set to `true`. This functionality requires a unittest.
